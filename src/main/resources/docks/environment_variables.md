# Как добавить переменные окружения в IntelliJ IDEA
## Пошаговая инструкция со скриншотами

Переменные окружения (environment variables) позволяют передавать настройки приложению без жёсткого кодирования их в исходном коде. Это удобно для хранения ключей API, параметров подключения к базе данных и других конфиденциальных или изменяемых данных. В этой инструкции вы узнаете, как задать переменные окружения для конкретной конфигурации запуска в IntelliJ IDEA.

---

### Шаг 1. Откройте проект
Запустите IntelliJ IDEA и откройте проект, в котором требуется настроить переменные окружения.

![**Скриншот 1** – открытый проект в IntelliJ IDEA.](screenshots/environment/Screenshot_01.png)

Вы находитесь в диалоге настройки конфигурации запуска `HomeRentApplication` и хотите добавить переменные окружения. Ниже — последовательность действий, которая продолжит ваш процесс.

---

### 1. Откройте окно редактирования конфигурации
Вы уже на шаге, где видно окно **Run/Debug Configurations** (скриншот [4](./screenshots/environment/Screenshot_4.png) и [5](./screenshots/environment/Screenshot_5.png)). Если нет – нажмите на выпадающий список конфигураций (зелёный треугольник) и выберите **Edit Configurations…**.

![**Скриншот 4** – окно редактирования конфигурации.](screenshots/environment/Screenshot_02.png)

или через меню: `Run` → `Edit Configurations…`.

![**Скриншот 4а** – меню с выделенным пунктом «Редактировать конфигурации…».](screenshots/environment/Screenshot_3.png)

Теперь вы видите список конфигураций слева и настройки выбранной конфигурации справа.

![Сриншот 4](./screenshots/environment/Screenshot_4.png)

Затем в правой части найдите раздел, связанный с переменными окружения. В разных типах конфигураций он может называться по-разному, но обычно это что-то вроде **Environment** или **Окружение**. Если вы не видите поле для переменных окружения, возможно, нужно прокрутить вниз или развернуть дополнительные настройки.

![**Скриншот 5** – раздел с полем для переменных окружения.](screenshots/environment/Screenshot_5.png)

### 2. Активируйте опцию «Environment variables»
На скриншоте 6 показано меню **Modify options** (кнопка в правом верхнем углу). 

![**Скриншот 6** – кнопка «Modify options» в окне конфигурации.](screenshots/environment/Screenshot_6.png)

Нажмите её и в разделе **Operating System** отметьте галочкой **Environment variables** (сочетание Alt+E).

После этого в окне конфигурации появится поле **Environment variables**.
![**Скриншот 7** – появившееся поле «Environment variables» после активации опции.](screenshots/environment/Screenshot_007.png)

### 3. Задайте переменные окружения
У вас есть два варианта:

![**Скриншот 7** – поле для ввода переменных окружения.](screenshots/environment/Screenshot_07.png)

#### Вариант А — ввести значения вручную
В поле **Environment variables** напишите переменные в формате:  
`ИМЯ1=значение1;ИМЯ2=значение2`  
Пример из скриншота 2:  
`EMAIL_FROM_USERNAME=email@example.com`

![**Скриншот 7а** – пример ручного ввода переменных окружения.](screenshots/environment/Screenshot_08.png)

#### Вариант Б — использовать файл `.env` 
Если вы хотите загрузить переменные из файла (например, `.env`), который лежит в папке `resources`:
1. Нажмите на кнопку выбора папки.

![**Скриншот 7б** – кнопка для выбора файла с переменными окружения.](screenshots/environment/Screenshot_7.png)

2. Откроется окно **Environment Files and Scripts**. Пока оно пустое.
3. Нажмите **+** (зелёный плюс) и выберите **файл .env** из файловой системы.

![**Скриншот 8** – окно для добавления файлов с переменными окружения.](screenshots/environment/Screenshot_8.png)

4. В появившемся диалоге выбора файла найдите и выберите файл `.env`, который лежит в `src/main/resources/`.
![**Скриншот 9** – выбор файла .env в файловой системе.](screenshots/environment/Screenshot_9.png)

5. После выбора файл появится в списке. Нажмите **OK**.

![**Скриншот 10** – добавленный файл .env в списке.](screenshots/environment/Screenshot_10.png)

### 4. Сохраните конфигурацию
Вернувшись в главное окно, нажмите **OK** или **Apply** (скриншот 4, 5, 7 – кнопки внизу).

### 5. Запустите приложение
Теперь при запуске через эту конфигурацию переменные из `.env` (или указанные вручную) будут доступны в приложении. Проверить можно, например, добавив в код `System.getenv("EMAIL_FROM_USERNAME")`.

---

## Важные замечания
- Формат файла `.env` — каждая переменная на новой строке:  
  `EMAIL_FROM_USERNAME=email@example.com`  
  `DB_PASSWORD=secret`

![**Скриншот 11** – пример содержимого файла .env.](screenshots/environment/Screenshot_2.png)

- Переменные, заданные в поле напрямую, имеют приоритет над переменными из файла, если указаны одновременно.
- Не забудьте, что файл `.env` не должен попадать в систему контроля версий (добавьте его в `.gitignore`), если содержит секреты.

Если у вас остались вопросы или нужна помощь с конкретными значениями — обращайтесь!
